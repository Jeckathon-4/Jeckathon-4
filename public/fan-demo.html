• 메인 화면은 풀스크린 야구장
• 비 / 해 누적에 따라 휴대폰 화면 전체가 어두워지거나 밝아짐
• 경기 종료 후 헌화하기를 누르면 장면 안에 꽃이 계속 쌓임
• 텍스트는 줄이고 상태 / 아이콘 / 이미지 중심으로 정리
승리하면 댄서 추가 버튼으로 클럽을 채우고 화면을 눌러 폭죽을 터뜨릴 수 있어요. 시연: 팀 선택 → 경기 입장 → 점수 조정 → 비/해 누르기 → 경기 종료 → 헌화하기 연타.
